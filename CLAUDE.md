# Counter-Strike Online World — notes for coding agents

Read `README.md`, then `docs/ARCHITECTURE.md` and `docs/DESIGN_SYSTEM.md` before changing anything. `apps/web/CLAUDE.md`
carries Next.js 16-specific guidance (generated by `next dev`) and `.claude/skills/payload` documents Payload CMS.

Ground rules:
- Facts come from the wiki (`wikiSource` on every entity); prose and translations may be AI-drafted but are reviewed by humans in the studio before publishing.
- Keep the soul: dark lobby, chamfers, CS orange accent, HUD numerals, designed fallbacks. No rounded corners, no generic component kits.
- Types flow from `packages/schema` (Zod) → collections → `payload-types.ts` (regenerate with `pnpm generate:types`) → `lib/world.ts` mappers → API + SDK.
- Run `pnpm lint:fix && pnpm typecheck && pnpm test` before finishing; `pnpm seed` must stay idempotent.
- Sandboxed agents cannot reach cso.fandom.com or its CDN; do not "fix" image loading by removing remote media — the user's machine and production can reach them.
- Media: infobox `portrait` is the hero; white-background `render` captures go through `pnpm ai -- restore` (see `docs/MEDIA_PIPELINE.md`) — never crop them raw into dark tiles.
